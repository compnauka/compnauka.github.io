Privacy Policy

Classroom Remote

Дата набуття чинності / Effective date: 15 вересня 2026 / September 15, 2026

Коротко: Classroom Remote синхронізує лише одну спеціальну Lesson Tab на явно підключених навчальних комп'ютерах. Він не читає історію браузера, вміст вебсторінок, паролі, cookies, файли, скриншоти або натискання клавіш.

1. Призначення

Classroom Remote — це інструмент синхронізації вкладки уроку для комп'ютерного класу. Авторизований учитель вибирає дозволений HTTPS-ресурс, а явно підключені пристрої відкривають або оновлюють лише власну Lesson Tab.

Пристрій пов'язаний із навчальним комп'ютером, а не з конкретним учнем. Учнівські облікові записи не створюються.

2. Дані, які не збираються

Classroom Remote не читає і не збирає:

  • ПІБ учнів або учнівські облікові записи;
  • історію браузера та адреси сторонніх вкладок;
  • вміст вебсторінок, форм або повідомлень;
  • паролі та cookies вебсайтів;
  • файли або завантаження;
  • скриншоти, записи екрана, аудіо чи відео;
  • натискання клавіш;
  • рекламні ідентифікатори або точне місцеперебування.

Розширення не використовує content scripts і не перевіряє вміст сторінки уроку.

3. Технічні дані

Локально у браузері

  • випадковий device ID і криптографічний device token;
  • призначена класом назва пристрою та назва організації;
  • остання застосована revision та ID спеціальної Lesson Tab;
  • стан підключення і синхронізації;
  • hostname поточного ресурсу уроку.

На сервері Classroom Remote

  • device ID, назва пристрою, hash device token та час enrollment;
  • поточний lesson URL, revision, status і час оновлення;
  • назва організації та список дозволених доменів;
  • створені вчителем назви й URL швидких посилань.

Відкритий device token повертається лише під час enrollment і не зберігається у серверній базі. Online presence та останній ACK прикріплені до активного WebSocket і не записуються як історія heartbeat.

4. Використання та передавання

Технічні дані використовуються лише для enrollment і автентифікації навчального комп'ютера, доставки та відновлення поточного стану Lesson Tab і показу вчителю статусу синхронізації.

Дані не продаються, не використовуються для реклами або профілювання і не передаються для сторонніх цілей. Cloudflare обробляє мережевий трафік та розміщує Worker як інфраструктурний постачальник сервісу.

5. Безпека та зберігання

Production-з'єднання використовують HTTPS або WSS. Навігація Lesson Tab обмежена HTTPS-адресами з дозволених учителем доменів. Device tokens є випадковими та зберігаються на сервері лише як SHA-256 hashes.

Device record зберігається до unenrollment. Lesson state та settings — до їх зміни, швидкі посилання — до видалення вчителем. Локальні дані залишаються до очищення даних розширення у браузері.

6. Дозволи браузера

Classroom Remote використовує лише storage, alarms та доступ до точного backend-origin Classroom Remote. Розширення не запитує <all_urls>, tabs, history, cookies, scripting, webRequest, downloads або desktopCapture.

Firefox-версія декларує лише обов'язкову категорію даних authenticationInfo: випадковий device ID, device token і призначену класом назву пристрою, необхідні для enrollment та доступу до стану кабінету.

7. Chrome Web Store Limited Use

Використання інформації, отриманої через Chrome APIs, відповідає Chrome Web Store User Data Policy, включно з Limited Use requirements. Інформація використовується лише для єдиної заявленої функції розширення.

8. Питання та видалення даних

Авторизований учитель може відключити пристрій у Teacher Dashboard. Для запитань, виправлення або допомоги з видаленням даних відкрийте звернення у Classroom Remote GitHub Issues.

English
Summary: Classroom Remote synchronizes only one dedicated Lesson Tab on explicitly enrolled classroom computers. It does not read browsing history, page content, passwords, cookies, files, screenshots, or keystrokes.

1. Purpose

Classroom Remote is a classroom lesson-tab synchronization tool. An authenticated teacher selects an approved HTTPS resource, and explicitly enrolled devices open or update only their dedicated Lesson Tab.

A device is associated with a classroom computer, not with an individual student. No student accounts are created.

2. Data we do not collect

Classroom Remote does not read or collect:

  • student names or student accounts;
  • browsing history or unrelated tab URLs;
  • page content, forms, or communications;
  • website passwords or cookies;
  • files or downloads;
  • screenshots, screen recordings, audio, or video;
  • keystrokes;
  • advertising identifiers or precise location.

The extension does not use content scripts and does not inspect lesson page contents.

3. Technical data

Stored locally in the browser

  • a random device ID and cryptographic device token;
  • the classroom-assigned device name and organization name;
  • the last applied revision and dedicated Lesson Tab ID;
  • connection and synchronization status;
  • the hostname of the current lesson resource.

Stored by the Classroom Remote service

  • device ID, device name, device-token hash, and enrollment time;
  • the current lesson URL, revision, status, and update time;
  • the organization name and teacher-approved trusted domains;
  • teacher-created saved-link labels and URLs.

The plaintext device token is returned only during enrollment and is not stored in the server database. Online presence and the latest ACK are attached to the live WebSocket and are not stored as heartbeat history.

4. Use and sharing

Technical data is used only to enroll and authenticate a classroom computer, deliver and recover the current Lesson Tab state, and show the teacher its synchronization status.

Data is not sold, used for advertising or profiling, or shared for unrelated purposes. Cloudflare processes network traffic and hosts the Worker as the infrastructure provider required to operate the service.

5. Security and retention

Production connections use HTTPS or WSS. Lesson Tab navigation is limited to HTTPS URLs from teacher-approved domains. Device tokens are random and stored on the server only as SHA-256 hashes.

A device record remains until an authenticated teacher unenrolls the device. Lesson state and settings remain until changed, and saved links remain until the teacher removes them. Local data remains until the extension's browser data is cleared.

6. Browser permissions

Classroom Remote uses only storage, alarms, and access to the exact Classroom Remote backend origin. It does not request <all_urls>, tabs, history, cookies, scripting, webRequest, downloads, or desktopCapture.

The Firefox version declares only the required authenticationInfo data category: the random device ID, device token, and classroom-assigned device name required for enrollment and access to the classroom state.

7. Chrome Web Store Limited Use

Classroom Remote's use of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Information is used only for the extension's single disclosed purpose.

8. Questions and deletion requests

An authenticated teacher can unenroll a device in the Teacher Dashboard. For privacy questions, corrections, or deletion assistance, open a request in Classroom Remote GitHub Issues.

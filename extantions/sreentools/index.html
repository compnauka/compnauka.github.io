Privacy Policy

This policy explains how the School Screen Tools browser extension handles information while providing drawing, highlighting and presentation tools over web pages.

Effective: 8 September 2026 Website: itnauka.org Extension: School Screen Tools
Short version: School Screen Tools does not send browsing data, drawings, page content or user activity to the developer or to third parties. Data needed for the extension’s functions is processed locally in the browser.

1. Purpose of the extension

School Screen Tools is a browser extension for teachers, presenters and other users who want to draw, highlight, point to and visually focus on elements directly over the web page currently being shown. The extension does not modify the original website itself.

2. Information handled by the extension

The extension may process the following information only as needed for its stated functionality:

Category What is processed Why Where
Web history The URL of the current page may be used when the user explicitly saves annotations. To associate saved annotations with the page on which they were created and restore them later. Locally in the browser.
User activity Pointer, mouse, touch or stylus coordinates are processed while the user draws or interacts with the annotation tools. To create lines, highlights, arrows, shapes, erasing actions and other on-screen annotations. Processed locally; not transmitted to the developer.
User-generated annotations Drawing strokes, text notes, arrows, rectangles and related annotation settings. To display the user’s annotations and, when the user chooses Save, restore them later. Locally in the browser.
Preferences Toolbar position, selected tools and other extension settings. To remember the user’s preferred configuration. Locally in the browser.
Website content: School Screen Tools does not collect or transmit the text, images, videos, passwords, form values, cookies or other content of the websites that the user visits.

3. How information is used

Information handled by the extension is used only to provide the extension’s single purpose, including:

  • displaying the drawing and presentation overlay;
  • processing pointer, mouse, touch and stylus input while annotation tools are active;
  • saving user preferences;
  • saving and restoring annotations when the user explicitly chooses to do so.

The developer does not use this information for advertising, profiling, analytics, marketing or creditworthiness decisions.

4. Data sharing and selling

School Screen Tools does not sell user data and does not transfer user data to third parties for advertising, analytics, marketing or unrelated purposes.

The extension does not operate a backend server for storing browsing information or annotations.

5. Local storage and retention

Extension preferences and saved annotations are stored locally using browser extension storage. They remain on the user’s device until the user clears saved annotations, resets the extension, clears browser extension data, or uninstalls the extension.

Because data is stored locally, the developer cannot access, restore or delete a user’s saved annotations remotely.

6. Browser permissions

activeTab

Used to activate School Screen Tools on the current page after an explicit user action, such as clicking the extension icon or using the configured shortcut.

scripting

Used to inject the extension’s packaged local JavaScript and CSS into the active page so that the annotation toolbar and drawing overlay can appear.

storage

Used to save extension preferences and, when the user explicitly requests it, saved annotations associated with a page.

Optional website access

If the user enables an automatic mode that requires broader website access, the browser may request optional permission to run the extension on HTTP and HTTPS pages. This permission is used only to display School Screen Tools on those pages and is not used to transmit page content to the developer.

7. Remote code

School Screen Tools does not execute remotely hosted code. Its JavaScript, CSS, HTML and application logic are packaged inside the extension. The extension does not load executable scripts from external servers or CDNs and does not use mechanisms such as eval() or Function() to execute remotely obtained code.

8. Security

School Screen Tools is designed to minimize data exposure by keeping extension data on the user’s device and avoiding unnecessary network transmission. Users should still protect access to their browser profile and device, because locally stored extension data is subject to the security of that device and browser profile.

9. Use in educational settings and by children

School Screen Tools is designed primarily as a presentation and teaching utility. The extension does not require an account and does not ask users to submit their name, email address, age, school, student identifier or other personal profile information.

The developer does not knowingly collect personal information from children through the extension.

10. Chrome Web Store Limited Use

The use of information received from Chrome APIs will comply with the Chrome Web Store User Data Policy, including its Limited Use requirements. Any information handled by School Screen Tools is used only to provide or improve the extension’s user-facing functionality and is not used for unrelated purposes.

11. Changes to this Privacy Policy

This Privacy Policy may be updated when the extension’s functionality, permissions or data handling changes. The effective date at the top of this page will be updated accordingly. Material changes will be reflected in the Chrome Web Store disclosures where required.

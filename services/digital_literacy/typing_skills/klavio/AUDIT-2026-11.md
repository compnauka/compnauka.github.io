# Аудит Клавіо — 23 листопада 2026

Перевірено на живому сайті itnauka.org (Chrome): парасолькова сторінка, Старт, Уроки, Слова, Спринт; для порівняння — Клавіатурний пазл.

## 1. Модель клавіатури (усі модулі)

| Вада | Як у справжній клавіатурі / у Пазлі |
|---|---|
| Ряди різної довжини: правий край «драбиною» (⌫, `\`, Enter, правий Shift, Ctrl закінчуються на різній висоті) | Усі ряди однакові — 15 одиниць (u), корпус прямокутний |
| Ширини спецклавіш приблизні (`medium`/`wide`/`xwide`) | ANSI: Backspace 2u, Tab 1.5u, `\` 1.5u, Caps 1.75u, Enter 2.25u, лівий Shift 2.25u, правий Shift 2.75u, нижній ряд по 1.25u, пробіл 6.25u |
| Нижній ряд праворуч: AltGr, Ctrl — немає Win і Menu | Alt (AltGr), Win, Menu, Ctrl |
| Підписи спецклавіш скорочені й без символів (Caps, Enter, ⌫) | «Caps Lock», «Enter ↵», «← Backspace», «Tab ↹», «⇧ Shift» |
| Картка вступу в «Уроках» лежить поверх ряду цифр напівпрозоро: крізь неї видно «7 8 9 0 =» — виглядає як збій | Картка не повинна перекривати клавіатуру або має бути повністю непрозорою й акуратною |
| Підгонка під висоту екрана є лише в «Уроках»; у «Словах» і «Спринті» на 1366×768 нижні ряди за краєм | Однакова підгонка в усіх модулях |

## 2. Мова: лише українська

Немає англійської розкладки, текстів і перемикача. Потрібен перемикач УКР / ENG на всіх сторінках (налаштування робочого місця), англійська розкладка для клавіатури, англійські набори в «Старті», англійський курс уроків, слова й речення, цілі «Спринту», правильне попередження про розкладку.

## 3. Педагогічна послідовність

- Парасолькова сторінка не пояснює маршрут (Старт → Уроки → Слова → Спринт), вік і як працювати в класі. Номери 01–04 натякають на порядок, але без пояснень.
- «Слова» не пов'язані з уроками: складність = довжина слова, тож після 5-го уроку учень отримує слова з невивченими літерами. Потрібен вибір «літери до уроку N» (або «усі літери»).
- «Слова» показують одне слово за раз, хоча в «Уроках» уже є велике поле з усім обсягом роботи. Для речень і рядка слів варто використати таке саме поле.
- У «Спринті» клавіатура з підсвіченою ціллю показана завжди, тож гра на швидкість не тренує сліпий друк. Потрібні режими підказок, як в «Уроках».
- У «Словах» немає режимів підказок і долонь з пальцями, хоча це наступний крок після «Уроків».
- Підсумки «Старту», «Слів» і «Спринту» не показують, які клавіші давалися найважче (в «Уроках» це вже є).
- Деякі сполучення в «Спринті» нетипові для мови («ерж», «юва», «обі»).

## 4. Узгодженість і впізнаваність UI

- Чотири різні тулбари: «Клавіо / Слова» є в «Словах» і «Спринті», але немає в «Старті» й «Уроках»; різні кнопки дії («Завершити», «Заново», «Почати/Зупинити»).
- Різні назви й набори показників: «симв/хв» (чипи), «СИМВ/ХВ» + «СЛІВ/ХВ» (картки), «Бали / Час / Серія / Темп».
- «Спринт» перед грою має 4 групи по 2–3 кнопки (12 варіантів) — забагато для дитини; «Зліва / Справа» мало зрозуміле.
- Кольори модулів (бірюзовий, фіолетовий, жовтий, червоний) — добре; їх варто послідовно використати в тулбарі кожного модуля.

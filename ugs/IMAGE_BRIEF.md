Для інтерфейсу підготовлено копії WebP у `assets/optimized/` зі збереженням структури папок. Оригінальні PNG не змінено. 54 оригінали займають приблизно 93 МБ; 54 вебкопії — приблизно 1,95 МБ.

Нові зображення вже є на головній, у виборі пристроїв, сортуванні, поясненнях, майстерні листівок і в алгоритмічному полі. Стрілки, кнопки та дрібні службові піктограми залишаються векторними.

## Предмети для вправ: наступна партія

Поточні вправи з тваринами, рослинами та побутовими послідовностями частково використовують SVG, оскільки відповідних PNG ще немає. Для єдиного стилю потрібні окремі прозорі зображення:

| Набір | Файли |
|---|---|
| Рослина | `seed.png`, `sprout.png`, `sunflower.png`, `tree.png` |
| Тварини | `cat.png`, `dog.png`, `lion.png`, `panda.png`, `giraffe.png`, `spider.png` |
| Транспорт | `bus.png`, `bicycle.png` |
| Продукти | `apple.png`, `carrot.png` |
| Погода | `sun.png`, `cloud.png`, `rain.png` |
| Безпека й навігація | `password-key.png`, `lock.png`, `browser-window.png`, `message.png` |
| Побутові дії | `wake-up.png`, `brush-teeth.png`, `get-dressed.png`, `take-backpack.png` |

Не обов’язково створювати всі набори одразу: частину завдань сортування вже переведено на наявні пристрої й файли. Найвищий пріоритет — рослина та персонажі/предмети, які лишилися в активних вправах.

## Окремі медіаматеріали

- Для кожного з 16 відеоуроків — обкладинка 16:9, коли буде готове відео. Текст назви краще додавати в інтерфейсі.
- Для уроку 4 потрібні також справжні короткі аудіоприклади: голос, музика, сигнал. PNG не може замінити звук. Зараз використовується синтезований короткий сигнал і доступний текстовий опис.
- Для відео як виду інформації бажаний короткий ролик із реальним рухом. Зараз є керована кнопкою анімація предмета.
- Для алгоритмічного поля достатньо нового Юджі та програмно намальованих клітинок, перешкод, стрілок і цілі. Нові повні ілюстрації кожного маршруту не потрібні.

## Спільні правила для генерації

1. Та сама зовнішність Юни та Юджі, пропорції, матеріали й освітлення, що в наданих PNG.
2. Синя, блакитна, лаймова й біла палітра UGS. Колір не підказує відповідь.
3. Один предмет або одна зрозуміла навчальна дія на зображенні.
4. Предмети — на прозорому фоні, без обрізаних частин і широких порожніх полів. Сцени — на простому світлому фоні.
5. Не генерувати дрібний текст, клавіатурні написи, URL, паролі, стрілки маршрутів і кнопки всередині картинки.
6. Правильний і хибні варіанти мають однакову якість, масштаб та емоційний тон.
7. Для набору послідовності зберігати ракурс, фон і склад предметів; змінювати лише навчально важливу дію.

Мапа використання наявних ілюстрацій: `js/icons.js`, об’єкт `assets`. Додавання сюжету до конкретного кадру потребує відповідного ключа або окремого рендерингу зображення; сам файл не підключається автоматично.

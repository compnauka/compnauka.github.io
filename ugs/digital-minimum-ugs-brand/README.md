# Digital Minimum — повний MVP, теми 1–4

Статичний сервіс «Цифровий мінімум початкової школи» для дітей 7–10 років.

У цій збірці реалізовано **всі 16 базових умінь**.

## Тема 1. Я користуюся пристроями
1. Я вибираю потрібний цифровий пристрій
2. Я безпечно керую цифровим пристроєм
3. Я вводжу інформацію

## Тема 2. Я працюю з інформацією
4. Я розрізняю текст, звук, зображення і відео
5. Я сортую інформацію
6. Я впорядковую дії та об’єкти
7. Я створюю, зберігаю і знаходжу свою роботу

## Тема 3. Я користуюся Інтернетом безпечно
8. Я користуюся сайтом та посиланнями
9. Я знаходжу потрібну інформацію
10. Я бережу особисту інформацію
11. Я знаю, що робити, коли онлайн щось не так
12. Я знаю, навіщо потрібен пароль

## Тема 4. Я думаю як програміст
13. Я даю точні команди
14. Я складаю алгоритм і маршрут
15. Я знаходжу та виправляю помилку
16. Я скорочую повторювані дії

Кожна навичка проходить цикл:

`Дивись → Запам’ятай → Спробуй → Потренуйся → Я вмію!`

## Технічні принципи

- чистий HTML + CSS + JavaScript;
- без npm, фреймворків, CDN і web-fonts;
- без бекенду й обов’язкових акаунтів;
- прогрес у `localStorage` з fallback;
- локальні SVG-іконки;
- mobile-first, але не mobile-only;
- keyboard/touch/mouse friendly;
- drag-and-drop не є обов’язковим способом відповіді;
- `prefers-reduced-motion`;
- `forced-colors`;
- жодного autoplay;
- offline shell через Service Worker;
- без сторонньої аналітики та рекламних SDK.

## Запуск

```bash
python -m http.server 8000
```

Відкрити `http://localhost:8000`.

Проєкт також можна без збірки розмістити на GitHub Pages.

- `THEME_01_DEVICES.md` … `THEME_04_ALGORITHMS.md` — методичні специфікації тем;

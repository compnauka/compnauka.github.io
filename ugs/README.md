# Цифрові суперсили × Ukrainian Global School

Робоча версія від 21.10.2026: **5 тем, 18 уроків**, українською для дітей 7–10 років. Статичні HTML/CSS/JavaScript, без збірки, реєстрації та сервера даних.

Збережені головна, вертикальна сторінка уроку, токени UGS, Юна/Юджі, локальні зображення й чинні тренажери. До них додані моделі/плани, піксельне кодування, перевірка інформації, спільна листівка та незалежний контроль.

## Запуск

Запустіть з кореня репозиторію:

    python -m http.server 8765

Відкрийте http://localhost:8765/ugs/ . GitHub Pages працює без додаткової збірки.

## Адреси й дані

- Нові посилання: skill.html?skill=device-choice та інші стабільні ключі з js/data.js.
- Новий номер за потреби: skill.html?order=7 — кодування.
- Старі skill.html?id=7 та lesson-07.html лишаються збереженням роботи; старі адреси не перенумеровуються мовчки.
- Прогрес v3 зберігається за skillKey та версією перевірки. Старий ключ v2 не змінюється. Деталі — MIGRATION_NOTES.md.
- Листівка й піксельний код мають окремі локальні ключі; вкладки зберігають свій стан до перезавантаження.

## Сторінка уроку

Запитання → поетапне ілюстроване пояснення → 3 картки → перша дія → 2–3 тематичні вкладки → творча дія за потреби → незалежна перевірка. Результат — після чотирьох дій/умов; повтори зберігають найкращий статус у межах версії.

Відеоуроки й субтитри ще не готові; використовуються пояснення. Є короткий локальний рухомий приклад в уроці 04. Українське озвучення залежить від голосів пристрою; текст завжди доступний.

## Перевірки

    node tests/validate.cjs
    node tests/rebuild.cjs
    node tests/home.cjs
    node tests/mobile-learning.cjs
    node tests/browser-smoke.cjs
    node tests/rebuild-browser.cjs
    node tests/assessment-browser.cjs

Браузерним тестам потрібен Playwright у NODE_PATH та запущений локальний сервер. UGS_TEST_URL змінює адресу, UGS_TEST_OUTPUT задає папку знімків. Глобальні пакети не потрібні для самого сайту.

Після зміни runtime-файлів: node tools/update-cache.cjs. Великі відео автоматично не кешуються; короткий навчальний motion.webm внесений явно.

## Документація

- UGS_DIGITAL_SUPERPOWERS_REBUILD_18.md — специфікація та погоджені уточнення.
- REBUILD_AUDIT.md — що збережено, адаптовано й додано.
- MIGRATION_NOTES.md — старі адреси й дані прогресу.
- CONTENT_MATRIX.md — поточні вправи та контрольні завдання.
- VIDEO_STATUS.md — стан медіа.
- QA_REPORT.md — перевірки та обмеження.

Контрольні набори ще уточнюються з власником; методична валідація, тестування з дітьми та повна матриця НУШ не завершені.

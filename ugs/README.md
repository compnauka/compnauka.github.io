# Digital Minimum — повний MVP, теми 1–4

Головну сторінку також перебудовано для першого відвідування: призначення й вік дітей, початок навчання, коротке пояснення уроку, вибір теми та згорнутий каталог. Прогрес показується після першої спроби. `node tests/home.cjs` перевіряє початковий екран, теми та стани повернення на 320, 360, 390, 768 і 1280 px.

Поточна структура: **одна сторінка — відео, пояснення, практика з п’ятьма вкладками, «Перевір себе»**. Див. [повний опис](LESSON_DOCUMENT.md). Пояснення переписано простими діями, пам’ятка доступна за потреби. Шапку, налаштування та завдання адаптовано до малих екранів. Деталі: [дитиноцентричні уроки й мобільна версія](CHILD_FIRST_LESSONS.md). Старі розділи документа нижче описують початкову версію з п’ятьма етапами.

## Технічні принципи

- чистий HTML + CSS + JavaScript;
- без npm, фреймворків, CDN і web-fonts;
- без бекенду й обов’язкових акаунтів;
- прогрес у `localStorage` з fallback;
- локальні SVG-іконки;
- mobile-first, але не mobile-only;
- keyboard/touch/mouse friendly;
- drag-and-drop не є обов’язковим способом відповіді;
- `prefers-reduced-motion`;
- `forced-colors`;
- жодного autoplay;
- offline shell через Service Worker;
- без сторонньої аналітики та рекламних SDK.

# Публікація cs.itnauka.org

Сайт розгортається як окремий Cloudflare Worker `itnauka-cs` зі статичними файлами з `cs/`.
Основний `wrangler.toml` і сайт itnauka.org не змінюються.

## Повторне розгортання

Із кореня цього репозиторію після оновлення папки cs:

```powershell
npx wrangler deploy --config wrangler.cs.toml --strict
```

Вхід у Cloudflare виконується через `npx wrangler login`, якщо сесія завершилася.
Секретів і токенів у репозиторії немає. Конфігурація прив'язує тільки `cs.itnauka.org`;
DNS-запис і сертифікат керуються Cloudflare Custom Domains.

Важливо: для підручника завжди вказуйте `--config wrangler.cs.toml`.
Команда без цього параметра використовує конфігурацію основного сайту.

## Індексація

Файл cs/_headers задає `X-Robots-Tag: noindex, nofollow, noarchive` для всіх ресурсів.
HTML також містить метатеги noindex. Обхід у robots.txt дозволено, щоб пошуковики
могли прочитати noindex. Cloudflare додає до robots.txt власні правила для ботів;
їхня наявність не скасовує HTTP-заголовок і метатеги noindex.

## Перевірка після публікації

- https://cs.itnauka.org/ — каталог з темами;
- https://cs.itnauka.org/#topic/1-1-1 — пояснення й інтерактивні вправи;
- https://cs.itnauka.org/#teachers — сторінка для вчителів;
- https://cs.itnauka.org/#search?q=scratch — пошук по всіх класах.

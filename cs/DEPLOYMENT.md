# Розміщення на itnauka.org

1. Скопіюйте вміст готової папки `cs` в однойменну папку репозиторію itnauka.org. Переносьте також приховані файли, зокрема `.nojekyll`.
2. Після публікації відкрийте `https://itnauka.org/cs/`. Для `https://cs.itnauka.org/` окремо налаштуйте DNS та хостинг, щоб коренем піддомену була папка `cs`.
3. Перевірте відкриття теми, гри та оновлення сторінки з адресою `#topic/1-3-1`. Усі шляхи відносні; rewrite-правила не потрібні.

Якщо це GitHub Pages, сама папка в репозиторії не створює окремий піддомен. Для піддомену зазвичай потрібен окремий Pages-сайт або інше налаштування хостингу. Не додавайте CNAME у підпапку навмання: він не призначає піддомен папці.

## Індексація

Всі HTML-файли мають метатеги `noindex, nofollow, noarchive` для роботів та Googlebot, включно з прямими адресами ігор. `robots.txt` дозволяє обхід, щоб роботи могли прочитати `noindex`: заборона обходу сама по собі не забороняє індексацію URL.

Файл `_headers` додатково встановлює `X-Robots-Tag` на Cloudflare Pages та сумісних хостингах. GitHub Pages не підтримує довільні HTTP-заголовки через цей файл; там працюватимуть метатеги HTML. На Nginx додайте в конфігурацію відповідного сайту:

```nginx
add_header X-Robots-Tag "noindex, nofollow, noarchive" always;
```

Якщо сайт розміщений у підпапці, пошуковики читають robots.txt лише з кореня домену. Метатеги кожної сторінки залишаються чинними. Перевіряйте, що кореневий robots.txt не блокує читання `/cs/`, якщо потрібно, щоб пошуковик побачив директиву noindex.

## Оновлення

Єдине джерело правди: `Grade_N/` (уроки), `app/` (ігри), `website/assets/` і `website/*.json` (інтерфейс і дані), кореневий `index.html`. Папка `cs/` повністю збирається командою `node tools/build-catalog.js` — вручну в ній нічого не правте. Після збирання виконайте `node tools/check-site.js` і скопіюйте вміст `cs/` на хостинг. Вчительські нотатки (`Grade_N/Teacher_notes`) на сайт не потрапляють; для вчителів призначена сторінка `#teachers`.
